# Number Guessing Game — Java Development 

## Objective
Console-based game where the computer picks a random number (1–100) 
and the user guesses it, receiving Too High / Too Low hints until correct.

## Tech Stack
Java (console application)

## Features
- Random number generation (1–100)
- Guess input via Scanner
- Attempt counter with a max limit (7 attempts)
- "Play Again" option after each round
- Score/summary tracking per round

## How to Run
1. Compile: `javac NumberGuessingGame.java`
2. Run: `java NumberGuessingGame`
